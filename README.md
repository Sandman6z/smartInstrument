# 自动化测试工具

## 项目概述

这是一个用于IT8811（电子负载）和DMM6500（数字万用表）设备的自动化测试工具，提供了直观的GUI界面，方便用户进行设备控制和数据采集。

## 主要功能

- **设备自动扫描与识别**：自动扫描可用的VISA设备，并识别IT8811和DMM6500设备
- **设备连接管理**：支持IT8811和DMM6500的连接、断开操作
- **IT8811控制**：
  - 电阻值设置（支持输入框和滑动条调节）
  - 输出开关控制（滑动切换按钮）
- **DMM6500测量**：实时测量电压值
- **数据记录**：
  - 手动触发数据采集
  - 数据实时显示在表格中
  - 数据保存到Excel和CSV文件
- **实时日志**：操作日志实时输出

## 技术特点

- 使用tkinter构建直观的GUI界面
- 使用pyvisa库与设备进行通信
- 使用openpyxl库操作Excel文件
- 采用多线程处理设备通信，避免UI阻塞
- 具有良好的错误处理和日志记录机制
- 支持多种设备命令格式，提高兼容性

## 安装与使用

### 1. 安装依赖

```bash
# 使用pip安装依赖
pip install -r requirements.txt

# 或使用uv安装依赖
uv install
```

### 2. 运行应用

```bash
python run.py
```

### 3. 使用步骤

1. 启动应用后，系统会自动扫描可用的VISA设备
2. 选择并连接IT8811和DMM6500设备
3. 设置IT8811的电阻值（可通过输入框或滑动条）
4. 控制IT8811的输出开关
5. 点击"手动触发记录"按钮采集数据
6. 数据会实时显示在表格中
7. 点击"保存数据到CSV"按钮保存数据

## 设备要求

- IT8811电子负载设备
- DMM6500数字万用表设备
- VISA驱动程序（需要提前安装）

## 依赖库

- pyvisa>=1.14.0：用于与设备通信
- openpyxl>=3.1.0：用于操作Excel文件

## 注意事项

1. 确保已正确安装VISA驱动程序
2. 确保设备已正确连接到计算机
3. 操作设备前请确保了解设备的基本操作方法
4. 数据采集过程中请勿断开设备连接

## 故障排除

- **设备未找到**：检查设备连接和VISA驱动安装
- **连接失败**：检查设备地址是否正确，设备是否正常工作
- **命令执行失败**：设备可能处于异常状态，尝试重新连接设备
- **数据采集超时**：检查设备响应时间，可能需要调整超时设置
