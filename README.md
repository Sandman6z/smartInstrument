# 智能仪器测试系统

基于Vue3 + Flask的智能仪器测试系统，用于控制和监控电子测量设备。

## 功能特性

- ✅ 设备自动扫描和连接管理
- ✅ IT8811电阻设置和输出控制
- ✅ 数据采集和手动触发
- ✅ 实时数据更新和可视化
- ✅ 测试数据表格展示
- ✅ 数据统计和分析
- ✅ 数据保存和清除

## 安装步骤

### 1. 安装Python依赖

使用uv管理Python依赖（推荐）：

```bash
# 在项目根目录运行
uv sync
```

或者使用pip：

```bash
# 在项目根目录运行
pip install -e .
```

### 2. 安装前端依赖

首先安装Node.js（[下载地址](https://nodejs.org/zh-cn/download/)），然后安装前端依赖：

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install
```

## 运行步骤

### 1. 启动后端服务

使用uv运行后端服务（推荐）：

```bash
# 在项目根目录运行
uv run .\backend\app.py
```

或者使用python：

```bash
# 在项目根目录运行
python backend/app.py
```

后端服务将在 `http://localhost:5000` 运行，提供API接口和WebSocket服务。

### 2. 启动前端开发服务器

```bash
# 在前端目录运行
npm run dev
```

前端服务将在 `http://localhost:3000` 运行，自动打开浏览器访问应用。

### 3. 访问应用

#### 3.1 浏览器访问

打开浏览器，访问 `http://localhost:3000` 即可使用智能仪器测试系统。

#### 3.2 桌面应用（Electron）

使用 Electron 启动桌面应用：

```bash
# 在前端目录运行
npm run electron:dev
```

这会同时启动前端开发服务器和 Electron 桌面应用，方便你进行开发和调试。

### 4. 构建桌面应用

在前端目录运行以下命令，构建可执行的桌面应用：

```bash
# 在前端目录运行
npm run electron:build
```

构建完成后，在 `dist-electron` 目录中找到生成的可执行文件：
- **Windows**：生成 `.exe` 安装文件和便携式可执行文件
- **macOS**：生成 `.dmg` 安装文件
- **Linux**：生成 `AppImage` 和 `.deb` 安装文件

## 使用指南

1. **扫描设备**：点击"扫描设备"按钮，系统会自动扫描可用的VISA设备
2. **连接设备**：选择设备资源，点击"连接"按钮连接设备
3. **设置参数**：在IT8811控制面板中设置电阻值和输出状态
4. **采集数据**：点击"手动触发记录"按钮采集数据
5. **查看数据**：在数据可视化面板中查看测试数据和图表
6. **保存数据**：点击"保存数据"按钮将测试数据保存到CSV文件

## 注意事项

1. **VISA驱动**：确保已安装NI-VISA或Keysight VISA驱动
2. **设备连接**：运行前请确保设备已正确连接到计算机
3. **防火墙**：如果无法连接，请检查防火墙设置
4. **端口占用**：确保端口5000（后端）和3000（前端）未被占用

## 故障排除

### 后端启动失败
- 检查Python版本：建议使用Python 3.8+
- 检查依赖安装：确保所有依赖已正确安装
- 检查VISA驱动：确保VISA驱动已正确安装

### 前端启动失败
- 检查Node.js版本：建议使用Node.js 16+
- 检查依赖安装：确保所有npm依赖已正确安装

### 设备连接失败
- 检查设备电源：确保设备已开机
- 检查USB连接：确保USB线缆连接稳定
- 检查VISA驱动：确保VISA驱动已正确安装
