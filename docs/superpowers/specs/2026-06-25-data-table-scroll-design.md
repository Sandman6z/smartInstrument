# 数据记录表格：冻结首列 + 水平滚动方案

## 背景

UI 底部的"数据记录"表格使用 `ttk.Treeview` 实现。每次触发采集动态新增一列，所有数据列设 `stretch=tk.YES`，导致列数增多时各列被压缩挤扁，数据难以阅读。

## 方案选择

从 4 个候选方案中选定 **方案 C：冻结首列 + 可滚动数据区**：

| 方案 | 描述 | 结论 |
|------|------|------|
| A. 修复水平滚动 | 固定列宽 + stretch=NO | ❌ 列多了仍需左右拖拽 |
| **B. 冻结首列 + 滚动** | **设备名固定，数据区独立滚动** | **✅ 选定** |
| C. 转置为行布局 | 触发=行，设备=列 | ❌ 横向对比不便 |
| D. 限制列数+分页 | 只显示最近 N 次 | ❌ 不能一目看全 |

## 实现架构

```
┌─────────────────────────────────────────────────────────┐
│                    数据记录 (LabelFrame)                  │
│  ┌──────────────┬──────────────────────────────────────┐ │
│  │  左 Treeview  │   右 Treeview (绑定水平滚动条)       │ │
│  │  (固定宽度)   │   (所有触发数据列)                   │ │
│  │              │                                      │ │
│  │  设备        │  触发1  触发2  触发3  触发4  ...     │ │
│  │  IT8811 ...  │  1.234  1.567  1.345  1.890  ...     │ │
│  │  DMM6500 ... │  5.001  4.998  5.012  5.003  ...     │ │
│  │  KEYSIGHT .. │  0.102  0.098  0.101  0.097  ...     │ │
│  │              │                         ←滚动条→      │ │
│  └──────────────┴──────────────────────────────────────┘ │
│                                     [清除测试数据]       │
└─────────────────────────────────────────────────────────┘
```

### 关键设计决策

1. **两个独立的 ttk.Treeview 并排放置**，用 `pack(side=tk.LEFT)` 排列
2. **左 Treeview**：仅显示设备名（`#0` 列），`stretch=tk.NO`，固定宽度约 150px
3. **右 Treeview**：动态添加触发数据列，`stretch=tk.NO`，每列固定宽度 85-90px
4. **水平滚动条**：绑定到右 Treeview，数据超出时自动出现
5. **同步行高**：两个 Treeview 的 `height` 属性保持一致（固定 3 行）
6. **清除数据**：左右 Treeview 同步清空

### 配色方案

低对比度、清爽风格：

| 元素 | 颜色 |
|------|------|
| 页面底色 | 透明（继承窗口） |
| 表格边框 | `#e8e8e8` |
| 左栏分割线 | `#ddd` |
| 表头底色 | `#f8f8f8` |
| 左栏底色 | `#fafafa` |
| 行间隔色 | `#fcfcfc` |
| 字体颜色 | `#999` |
| 表头字体 | `#999`，weight=500 |
| 表头分隔线 | `#eee` |
| 行分隔线 | `#f5f5f5` |
| 滚动条 | 默认系统样式 |

### 数据流

- `add_data_column(col_index, resistance, voltage, current)` → 右 Treeview 新增数据列
- 左 Treeview 在初始化时一次性写入 3 个设备名，后续不变
- `clear_data()` → 左右 Treeview 同步清空数据列

### 影响范围

| 文件 | 改动 |
|------|------|
| `src/smart_instrument/gui/components/data_panel.py` | 重写 `create_widgets()`，新增 `_create_left_tree()` 和 `_create_right_tree()` |
| `src/smart_instrument/data/manager.py` | 无需改动（数据模型不变） |
| `src/smart_instrument/gui/main_window.py` | 通常无需改动，除非需要传递额外参数 |

### 未纳入范围

- 垂直滚动：只有 3 行数据，无需垂直滚动
- 列排序/编辑/选中：保持当前只读表格风格
- 自适应列宽：固定列宽，不随内容变化
